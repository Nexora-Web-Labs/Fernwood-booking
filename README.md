# Fernwood Studio — Booking Flow

A validated 5-step salon appointment booking flow built with React + Vite.

## Run it
```
npm install
npm run dev
```

## Features
- Step-gated navigation — each step validates before you can continue
- Deterministic per-date availability grid for time slots
- Review step with jump-to-edit links back to any prior step
- Real downloadable `.ics` calendar file generated client-side on confirmation
